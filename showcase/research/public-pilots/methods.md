# 公开导频的可靠性收益与参数泄漏代价

本研究只研究现有三层近似传播链路。频率0.7 THz，三层各16×16单元，设计C从25种候选中实际选用24种，接收假设得到双偏振复电场。原FDTD库、几何、相位参考面、传播网格和码元编码均冻结；没有新增FDTD、训练器件或实物实验。

## 一个导频是什么

原程序的一个导频是单独发送的完整空间图案，包含16个已知BPSK码元；每个码元覆盖4×4个真实单元。接收每幅图案得到2×64×64=8192个复数分量。这8192个分量不是8192次独立发送。本研究增加的专用训练帧数量记为K，公开训练码元为16K，额外时间为K帧时间。

主实验消息固定为4个随机ASCII字符：32负载位，加16位长度和32位CRC，共80位，分5个数据帧。专用训练在数据之前。发送能量以原input场范数计，一帧为1，每码元1/16；未假定激光功率和秒数，因此不将此数写成焦耳或毫秒。固定每码元能量时总量为5+K；固定总能量对照保持为6，只调整入射幅度，探测噪声保持原方差。

审计还发现固定4字节范围使第一个数据帧0x0004长度头成为已知完整输入。故K=0只是没有额外专用导频，接收方仍可能利用一个公开长度帧。原协议文件保留，并在正式实验前新增amendment_header.json；长度头对照复用同一观测，不增加发送成本。

## 数据流

```
独立私有样本清单 ──→ 发送端（消息、实际参数、配对噪声）
                          │
                专用训练帧 → 双偏振复场观测
                          │
           公开模型、已知训练 → 参数/共同复增益估计
                          │
                5个数据帧 → 线性解码 → CRC及输出比特
                          │
独立评价真值 ──────────────→ 仅此处计算负载BER/完整恢复/参数误差
```

自适应运行时，发送端依次收到追加请求。停止判据只取得已发送训练帧，不得到负载或未来训练。它用前K−1幅拟合，最后一幅独立检查预测残差；决定停止后才发送数据。每次STOP/CONTINUE反馈计1个公开逻辑位，未计入未建模的物理控制包延迟和能量。最大预算用尽不等于成功停止。

## 双方信息权限

|信息|L|E1|E2|理想参考|评价器|
|---|---|---|---|---|---|
|模型、单元库、器件几何、训练序列|公开|同一份|同一份|同一份|可读|
|同一次观测、噪声方差、停止反馈|可读|同一份|同一份|同一份|可读|
|预先约定的16选1标称通道|已知本会话选择|只知全部16种及邻域|与L相同|已知|可读|
|实际连续偏差参数|不可读|不可读|不可读|仅诊断可读|可读|
|原始消息、目标比特、真实BER|不可读|不可读|不可读|不可读|接收后可读|

L的优势来自事先共享的离散配置，不来自合法身份；16种选择相当于最多4比特的离散先验信息，不能当作安全密钥强度。L/E2独立运行同一函数，分别检查专用导频和长度头信息条件的逐会话一致性。

每个接收输出附观测ID。E1在公开16个中心筛选后进行多初值连续优化，预算比L更大；K=0保留公开16候选的CRC枚举。CRC只供接收方检错与选候选，最终完全正确与否由独立评价器按比特确认。信息对等没有被解释成保密性。

L/E1主列只用专用导频，属于信息使用量对照。L_header/E1_header也用长度头，才利用了这里已识别的全部公开完整输入。linear/linear_header直接拟合已知输入与观测的线性解码关系，不要求猜对物理参数。未知负载未被拿来训练。

## 固定协议与统计

protocol.json与private/session_manifest.json在实验前锁定。标称通道均匀抽取；偏振/转角偏差范围±2°，间距±0.2mm，各自均匀分布。L仅知道此前预配置的中心及±3°/±0.3mm搜索范围。无噪声、参考SNR40及60dB，各含标称、单偏振、单转角、单间距和联合偏差。

参考SNR以16个标称通道、均匀随机BPSK图案的平均探测功率定义。每个探测复分量加圆对称复高斯噪声，方差不随图案或预算重新归一化；不同实际场的实际SNR可以不同。固定预算之间共享对应标准噪声，预算内所有接收器共享同一实际观测。

每条件6个调参会话、30个选型验证会话。只有预先指定的联合偏差/60dB单元在验证集找到候选后，才使用299个新的确认会话检验固定1帧、候选较少固定方案和按需方案。单侧95%精确下限≥99%才确认；这是逐方法区间，不是多重比较同时置信保证。30次零失败不能确认99%。K为离散已测方案，不能宣称理论最少。

公开训练增加至16帧时输入矩阵满秩；16→32→48累计训练重复完整基、加入独立噪声，秩不再增加。累计对照的10个独立参数簇是统计单元，不把同一参数簇中的多个消息和预算重复当作独立会话。

## 数值加速与限制

最终固定传播映射做保留全部列的QR变换，观测压缩为512个复坐标；候选无关的正交噪声被去除，最小二乘与原全场等价。距离角谱用40阶Taylor求值，与原Operator的12组对照误差约10⁻¹⁴，远低于预设10⁻⁹门槛。原始数据仍保存8192复分量。停止阈值按512复坐标的噪声能量定义，不直接沿用原全场相关分数。

本机SciPy1.4的Powell不支持bounds，故通过tanh坐标显式保持参数在已核验邻域内。局部搜索预算耗尽也保留候选与失败状态。模型预测次数、相当于多少图案的预测量、真实运行秒数以及公共预处理开销分别记录；Gram评分并不表示每次重新运行了一次FDTD。

近直角±3°范围内原粗网格的最近邻结构映射不变，连续角度作用主要表现为Jones响应变化。这是原模型分辨率限制，不能把参数估计精度解释成真实器件角度精度。当前E1可读取公开反馈，但没有建立针对停止次数的额外似然攻击；模型、线性基线及有限预算的经验恢复都不等于穷尽攻击。

研究的新增内容是冻结器件条件下，对专用导频、隐含已知长度帧、可靠性、开销和未知参数恢复能力的配对量化。训练序列、按需停止和线性已知明文恢复均有文献基础，不声称首次。文献来源见literature/文献依据.md。
