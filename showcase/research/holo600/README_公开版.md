# Trikey：600×600×3 公开成果

本页展示真实 FDTD 单元响应驱动的三层近似传播结果。结构、指标和图片来自已经完成并保存的计算，**GitHub Pages 上不运行 Python 或 FDTD，不作连续参数实时重算**。

## 怎样使用

进入 Trikey 的“动态全息”。鼠标拖动查看三层结构，滚轮缩放，点击层面或输入行列查看真实32×32局部柱阵列。远景纹理使用全部600×600位置，未创建百万个浏览器对象；颜色表示几何尺寸，不是光强。

在“已计算条件”中选择72个已归档条件之一，观察同一个固定器件的实际探测强度及NCC/PSNR/SSIM。这里切换的是保存的结果；未计算的条件不能用当前图片替代。相同目标、相同强度标尺，超出显示上限的像素数另列，指标始终用未量化原始浮点数据。

第三层出口/相位及8曝光相移图只在确实保存的条件下提供。匹配条件的相移图来自已知理想参考光测量假设，双偏振各4次曝光，恢复同一探测面；不是普通单张强度图自动恢复相位，也不是新硬件实验。

## 已实际完成

- 三层各600×600，共1,080,000个独立结构位置；每个位置选择同一真实几何对应的x/y复响应。
- 原25种候选几何全部被新设计使用；真实优化35轮，109,537个位置相较随机初始化改变。随机初始状态没有被标为优化完成。
- 72组预定参数条件各自重新传播，保留真实复场及指标。另有5次已冻结网页操作记录，此公共包不包括之后用户在本机进行的交互。
- 设计参数 α=0°、θ₂=0°、d₂₃=6 mm，NCC=0.748958、PSNR=12.0177 dB、SSIM=0.034450。相关性改善不代表高保真已达标。

## 物理尺度与假设

频率0.7 THz；真空波长428.27494 μm；周期110 μm；600周期对应66 mm×66 mm。硅柱与有限基底各500 μm，硅折射率3.42、无损近似仍为项目文献借用/假设参数，不能称原论文参数定量复现。

L1到L2入口面距5 mm，L2到L3入口面距为d₂₃，L3入口面到探测面距5 mm。单元复响应已含1 mm柱/基底相对等长空气的响应，不重复增加基底厚度。旋转同时处理结构位置和固定实验坐标的Jones主轴。

## 数据与追溯

- `design_600.npz`：真实结构与成对复响应；`indices.bin`：108万个库编号；`library.json`：清洗后的真实库参数。
- `cases.json`、`scans.json`：72条件的原始数值指标与稳定记录ID；`cases/每个ID/result.json`：参数、来源SHA与图像。
- `validation.json`：未放宽阈值的检查记录；`figures.json`：14张科研图及其原始文件SHA；`manifest.json`：公共文件清单与指纹。
- 此包未包含72份完整复场及本机日志。原始计算文件保留在研究项目，公共记录提供SHA供核对，不把不存在的在线文件伪装为下载链接。

本机已有项目可以运行“启动600全息展示.cmd”进行连续参数实际重算；线上页面不主动访问本机端口，也不要求评委安装Python。
