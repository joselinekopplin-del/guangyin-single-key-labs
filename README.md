# 三维联合密钥光学通信仿真

偏振、第二层旋转角、L₂–L₃ 间距同时进入同一个光学传播与接收算子。网站采用科学简洁的统一布局。

- [联合实验入口](https://joselinekopplin-del.github.io/guangyin-single-key-labs/)
- [联合实验直接链接](https://joselinekopplin-del.github.io/guangyin-single-key-labs/joint/)

原 polarization、rotation、spacing 三个网址自动进入联合版。原版 PRISM 站点与 MD²NN 站点未被改动。

## 快速操作

1. 选择发射通道。默认字符 B 对应 α = 90°、θ = 90°、d = 10 mm，三个维度都有独立意义。
2. 输入短文字，点击“生成并传输密文”，再用当前三个接收参数恢复。
3. 改变接收参数后再次恢复。密文 SHA-256 标识保持相同；没有重新加密来替代一次传输的不同接收结果。
4. 点击“小幅同步偏差”，先恢复观察 BER，再运行导频联合校准、应用估计参数并再次恢复。
5. 运行联合容差地图、同帧八组消融对照，下载 CSV 或完整 JSON。

文字上限 122 个 UTF-8 字节。JSON 包含输入文字、仿真参数与实验结果，请按自己的分享范围使用。全部光场与文字运算发生在浏览器，不向应用服务器提交消息。

## 项目新增的验证功能

- **公开导频辅助三参联合校准**：在接收初值附近五轮细化搜索，最大化公开导频复场相关性；搜索不接收发射密钥和原文。导频同时估计共同载波相位与增益。
- **联合容差地图**：固定当前偏振，实际计算转角—层距 9 × 9 网格，显示 NCC 并导出 81 点数据。
- **同帧逐维错钥消融**：固定同一密文、噪声和器件扰动，计算全部正确与七类错误组合的 BER、CRC、图像 NCC 和导频相关性。

研究基础与原创性边界见 [方案和文献说明](research/joint-design.md)。三维融合已有论文；新增功能属于本项目的整合、同步与评估改进，当前不宣称全球首创或密码学安全认证。

## 光学与接收模型

复用已有的三层、16 通道联合训练权重：H/V × 四个直角 × 6/10 mm，对应字符 0–F。相位面 64 × 64，双折射 Jones 模型；128 × 128 零填充角谱传播；532 nm、8 μm 数值采样。固定两段传播为 4 mm。该采样间隔不是纳米结构周期。

全息部分用三维联合参数直接传播光场。文字部分将 1024 个空间 BPSK 码元经同一三层算子传播；接收端假设可以测量双偏振振幅和相位，使用 16 次共轭梯度求解。普通相机的单幅强度图不满足该接收假设。

公开导频是另一帧已知 BPSK 符号，不是额外秘密密钥。加工误差采用固定种子的独立高斯相位扰动；测量噪声及填充按每次会话生成随机种子。器件误差不随接收参数变化，错钥比较复用缓存复场。

CRC 只检错。BER 用保存的发射比特作事后数值评估，不参与接收判决。解码器不会比较发射和接收密钥是否相等来强制成功或失败。16 个公开离散通道只构成组合标签，可遍历，不是高强度密码。

## 字体与页面

白底、冷灰分区、蓝色交互提示。中文正文使用宋体 SimSun，英文数字优先 Times New Roman；原生 MathML 使用 Cambria Math。缺少对应字体的设备按 CSS 回退，不分发商业字体文件。

## 本地运行和验收

Node.js 18+，运行时无第三方依赖。

```sh
npm run build
npm start
# http://127.0.0.1:4178/
npm test
npm run benchmark
# 安装 Playwright 并使用 Windows Edge 或 Chromium：
npm run test:browser
```

可设置 LAB_URL 对 GitHub Pages 做同样的浏览器验收。qa/ 为忽略的截图和测试输出目录。

`build-joint.cjs` 生成统一网页与旧网址跳转；`joint-engine.js` 实现固定帧编码、接收、校准和分析；`joint-worker.js` 保持通信帧缓存；`joint-app.js` 管理交互。原 `engine.js` 与 `model-data.js` 为已有传播模型和训练权重。旧单变量界面源码保留作历史参考，发布入口使用联合版生成器。

验收覆盖 16 个标称通道、固定密文多次接收、导频校准、8 组消融、81 点容差、CSV/JSON 下载、旧网址跳转、手机无横向页面溢出和字体配置。数值基准只是代表性固定种子样例，未提供统计置信区间、器件实测或密码安全认证。
