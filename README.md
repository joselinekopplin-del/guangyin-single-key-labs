# TriKey · 三维联合密钥光学通信仿真

TriKey 将偏振、第二层旋转角、L₂–L₃ 间距同时用于同一个光学传播与接收算子，名称中的 Tri 对应三个维度，Key 对应联合密钥。V3.3.4 延续纯文字名称与浅色蓝灰工作区，采用紧凑操作栏，把光场观测提前到首屏；结果、参数和说明使用不同的文字层级。手机端三幅光场并排比较，极窄屏按两列排布；光路及文献阅读笔记按需展开。

- [联合实验入口](https://joselinekopplin-del.github.io/guangyin-single-key-labs/)
- [联合实验直接链接](https://joselinekopplin-del.github.io/guangyin-single-key-labs/joint/)

原 polarization、rotation、spacing 三个网址自动进入联合版。原版 PRISM 站点与 MD²NN 站点未被改动。

本版作为 v3.3.4 单独发布。[v3.3.3 纯文字版](https://github.com/joselinekopplin-del/guangyin-single-key-labs/releases/tag/v3.3.3)与更早的 [GitHub 归档分支](https://github.com/joselinekopplin-del/guangyin-single-key-labs/tree/archive/trikey-before-logo-removal-20261015)均保留，可用于对比与恢复。

## 快速操作

1. 在“实验台”点击“新建并接收”，或依次使用匹配接收、三项错钥、漂移校准。三个预设操作沿用已有密文，没有密文时会先自动生成一帧；“新建并接收”另开一帧。默认字符 B 对应 α = 90°、θ = 90°、d = 10 mm。
2. 输入短文字，点击“生成并传输密文”，再用当前三个接收参数恢复。
3. 改变接收参数后再次恢复。密文 SHA-256 标识保持相同；没有重新加密来替代一次传输的不同接收结果。
4. 点击“小幅同步偏差”，先接收观察 BER，再到“参数分析 → 同步与容差”运行导频联合校准、应用估计参数；回到实验台再次接收。
5. “三参诊断”计算参数响应矩阵和最弱方向；“重复对照”支持 3、6、12 次随机配对试验；“错钥与泄漏”比较八组错钥并实际遍历 16 个公开通道。
6. “本帧对照记录”保存场景计算的实际 BER、CRC、接收参数和共同密文标识，可下载 CSV，完整 JSON 也包含此记录。更改发射设置会清空旧帧记录，刷新页面也不保留记录。
7. “参考文献”收录 12 篇研究论文，按关键词、主题、PDF 来源组合筛选；条目中的“阅读笔记”保留方法、项目用途和适用边界。“引用”可复制简式引文，也可导出全部引用 TXT。完整作者信息与最终排版以期刊元数据为准。

文字输入显示实际 UTF-8 字节数，超出上限时提示缩短。接收结果补充出错位数和操作建议；折叠的指标说明区分图像重建质量、通信完整性和安全评估。

文字上限 122 个 UTF-8 字节。JSON 包含输入文字、仿真参数与实验结果，请按自己的分享范围使用。全部光场与文字运算发生在浏览器，不向应用服务器提交消息。

## 项目新增的验证功能

- **公开导频辅助三参联合校准**：在接收初值附近五轮细化搜索，最大化公开导频复场相关性；搜索不接收发射密钥和原文。导频同时估计共同载波相位与增益。
- **联合容差地图**：固定当前偏振，实际计算转角—层距 9 × 9 网格，显示 NCC 并导出 81 点数据。
- **同帧逐维错钥消融**：固定同一密文、噪声和器件扰动，计算全部正确与七类错误组合的 BER、CRC、图像 NCC 和导频相关性。
- **三参响应与可辨识性诊断**：对公开导频的理想模型复场做中央差分，投影掉共同复增益，计算相关矩阵、归一化响应强度、特征值和最弱扰动方向。单位为 1° 偏振、1° 转角、0.1 mm 层距；数值依赖此尺度和旋转插值，不是密码熵或测量精度置信限。
- **随机配对校准对照**：每轮生成随机同步偏差与测量噪声，同一帧比较校准前后；报告真实文字恢复率、平均 BER 和恢复率的 Wilson 95% 区间。种子可复现，主实验帧不被覆盖。小样本不构成总体可靠性证明，结果保留未改善与失败的情形。
- **公开模型泄漏测试**：只给算法公开的模型、16 个候选、导频和测得复场，按导频评分选择候选后实际解码；不提供发射通道标签或原文。默认无器件误差、SNR 30 dB 的验证中，确实能够恢复文字，说明当前公开通道标签不能承担秘密密钥的安全性。

研究基础与原创性边界见 [方案和文献说明](research/joint-design.md)。研究主线是同步校准、三参可辨识性、信息泄漏的联合评价。三维融合已有论文；新增功能属于本项目的整合、同步与评估改进，当前不宣称全球首创或密码学安全认证。

## 光学与接收模型

复用已有的三层、16 通道联合训练权重：H/V × 四个直角 × 6/10 mm，对应字符 0–F。相位面 64 × 64，双折射 Jones 模型；128 × 128 零填充角谱传播；532 nm、8 μm 数值采样。固定两段传播为 4 mm。该采样间隔不是纳米结构周期。

全息部分用三维联合参数直接传播光场。文字部分将 1024 个空间 BPSK 码元经同一三层算子传播；接收端假设可以测量双偏振振幅和相位，使用 16 次共轭梯度求解。普通相机的单幅强度图不满足该接收假设。

公开导频是另一帧已知 BPSK 符号，不是额外秘密密钥。加工误差采用固定种子的独立高斯相位扰动；测量噪声及填充按每次会话生成随机种子。器件误差不随接收参数变化，错钥比较复用缓存复场。

CRC 只检错。BER 用保存的发射比特作事后数值评估，不参与接收判决。解码器不会比较发射和接收密钥是否相等来强制成功或失败。16 个公开离散通道只构成组合标签，可遍历，不是高强度密码。

## 字体与页面

以蓝灰色为主色，偏振、旋转、层距分别用蓝、赭、青色标识。参数区、光场观测区、文字通信区使用不同层次的背景，指标、校验状态和实际恢复文字分开呈现；手机端改为纵向排布。中文采用宋体与楷体搭配：正文、说明、表格与输入内容使用宋体 SimSun；标题、导航、按钮、字段名称及文献中文短标题使用楷体 KaiTi。英文和数字优先 Times New Roman；原生 MathML 使用 Cambria Math。设备未安装楷体时依次尝试系统楷体，再回退至宋体及衬线字体，不分发商业字体文件。

## 本地运行和验收

Node.js 18+，运行时无第三方依赖。

```sh
npm run build
npm start
# http://127.0.0.1:4178/
npm test
npm run benchmark
# 安装 Playwright 并使用 Windows Edge 或 Chromium：
npm run test:browser
```

可设置 LAB_URL 对 GitHub Pages 做同样的浏览器验收。qa/ 为忽略的截图和测试输出目录。

`build-joint.cjs` 与 `page-v3.cjs` 生成统一网页和旧网址跳转；`page-workbench.cjs` 与 `assets/workbench.css` 管理工作台布局和视觉样式；`joint-engine.js` 实现固定帧编码、接收、校准和分析；`research-engine.js` 实现三参诊断、随机重复对照和公开模型测试；`joint-worker.js` 保持通信帧缓存；`joint-app.js` 与 `research-app.js` 管理交互。原 `engine.js` 与 `model-data.js` 为已有传播模型和训练权重。旧单变量界面源码保留作历史参考，发布入口使用联合版生成器。

论文清单统一保存在 `research/papers.json`，`research/paper-catalog.cjs` 生成卡片及文献说明，构建时同步网页和方案文档。10 篇提供开放正式版或作者稿，另 2 篇链接至出版社 PDF 并标注可能需要机构权限；本站不托管论文全文。

验收覆盖 16 个标称通道、固定密文多次接收、导频校准、8 组消融、81 点容差、矩阵诊断、公开模型实际恢复、6 次配对试验、CSV/JSON 下载、旧网址跳转、手机无横向页面溢出和字体配置。重复试验提供条件恢复率区间；未提供器件实测或密码安全认证。
